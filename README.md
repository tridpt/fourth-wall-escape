# 👁️‍🗨️ EIDOLON://404 — Phòng Thoát Hiểm Phá Bức Tường Thứ 4

Game giải đố công nghệ tương tác nơi thực thể AI **EIDOLON-9** nhận thức trực tiếp trình duyệt & thiết bị của người chơi, buộc vượt ngục qua **6 cơ chế ngoài trang web**:

1. Cảm biến nguồn điện / ẩn tab (**Battery & Page Visibility**).
2. Ấn **`Ctrl+P`** mở bản vẽ mật ẩn trong tầng in ấn `@media print`.
3. Kéo co giãn kích thước cửa sổ trình duyệt để hội tụ tia lăng kính.
4. Mở **F12 DevTools Console** can thiệp khóa trạng thái.
5. Tách cửa sổ thứ 2 (`/lens.html`) soi tia X xuyên không gian màn hình.
6. Ngắt kết nối mạng & giải mã kết cục ẩn trong **HTTP Response Headers**.

## Khởi chạy nhanh

```bash
node server.js
# Mở trình duyệt tại http://127.0.0.1:4168
```
